# PsiakApka

Polskojęzyczna, mobilna aplikacja PWA dla właścicieli psów.

## Uruchomienie
1. Rozpakuj archiwum.
2. Uruchom przez lokalny serwer HTTP/HTTPS (Service Worker nie działa z `file://`).
3. Otwórz `index.html` przez serwer, np. `python -m http.server 8080`.
4. Dane są przechowywane w `localStorage`.

## Funkcje
- onboarding 7 kroków,
- profil psa i autouzupełnianie ras,
- harmonogram i checklisty,
- nawodnienie z wykresem 7 dni,
- zapasy i karma,
- zdrowie,
- budżet pupila,
- karta SOS / Pet-Sitter,
- eksport i import JSON,
- manifest PWA i Service Worker,
- responsywny interfejs mobile-first.

Interfejs, etykiety i przykładowe dane aplikacji są po polsku.
